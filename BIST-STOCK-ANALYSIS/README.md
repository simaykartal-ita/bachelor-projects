# BIST Stock Analysis

## Project Overview

This project was developed as part of an academic course project and focuses on the analysis of historical stock price data from Borsa Istanbul (BIST).

The dataset contains intraday price observations for approximately 60 BIST-listed stocks between 2012 and 2019. The project includes data preprocessing, missing-value analysis, exploratory data analysis, visualization, and time-based examination of stock price behavior.

## Objectives

- Explore and preprocess historical BIST stock price data
- Investigate missing observations across different stocks
- Analyze stock price movements over time
- Identify patterns and characteristics in the dataset
- Visualize stock price data using Python

## Dataset

The dataset consists of approximately 50,000 timestamped observations and 60 stock price series.

The observations cover the period from 2012 to 2019 and contain intraday stock price measurements.

> The original dataset is not included in this repository.
